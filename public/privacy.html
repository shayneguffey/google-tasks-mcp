Privacy Policy — Claude Tasks

Last updated: October 31, 2026

Claude Tasks is a personal, single-user connector. It is used only by its owner to let Claude access the owner's own Google Tasks. It is not offered to the public.

What data it accesses

With the owner's consent (Google scope https://www.googleapis.com/auth/tasks), it reads and modifies the owner's Google Tasks: task lists, task titles, notes, due dates, and completion status.

How the data is used

Task data is fetched from Google only when Claude makes a request on the owner's behalf, and is returned to the owner's Claude session to answer that request. It is not used for advertising, analytics, profiling, or any other purpose.

Storage and sharing

The connector does not store task data. It keeps only a short-lived Google access token in memory and the owner's OAuth credentials as encrypted server environment variables. Task data is not sold or shared with anyone other than being returned to the owner's Claude session (operated by Anthropic) when the owner asks for it.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions can be sent to the support email shown on the Google sign-in consent screen for this app.
